# 🏋️ FitGenie AI

An AI-powered Fitness Assistant built using Python, Streamlit, LangChain, Ollama, and RAG.

## 🚀 Features

- 💪 Personalized Workout Plans
- 🥗 Diet Recommendations
- 💊 Supplement Guidance
- 🔥 Calorie Calculator
- 🍗 Protein Calculator
- ⚖️ BMI Information
- 📚 RAG-based Knowledge Retrieval
- 🤖 Offline AI using Llama 3.2

## 🛠️ Tech Stack

- Python
- Streamlit
- LangChain
- Ollama
- Llama 3.2
- ChromaDB
- HTML (inside Streamlit)
- CSS

## ▶️ Installation

Clone the project

```bash
git clone <repository-link>
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run Ollama

```bash
ollama run llama3.2
```

Start Streamlit

```bash
streamlit run app.py
```
